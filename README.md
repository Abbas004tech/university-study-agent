# 🎓 University Study Assistant

## Overview

University Study Assistant is an AI-powered educational platform developed using Python, Streamlit, and Google Gemini AI.

The application helps students transform their study materials into structured learning resources such as notes, summaries, quizzes, flashcards, MCQs, and study plans.

---

## Features

### 📂 File Upload

* PDF Upload
* PPTX Upload
* Multiple File Upload Support

### 📚 Notes Generator

* Detailed Study Notes
* Exam-Oriented Content
* Structured Formatting

### 📝 Summary Generator

* Concise Revision Notes
* Quick Learning Material

### 🎯 MCQ Generator

* AI Generated MCQs
* Exam Preparation Support

### 🧠 Flashcards Generator

* Active Recall Learning
* AI Generated Flashcards

### ❓ Quiz Mode

* Quiz Generation
* Self Assessment

### 📅 Study Planner

* Personalized Study Schedule
* Exam Preparation Roadmap

### 📄 Export Support

* PDF Download
* DOCX Download

### 📜 History Tracking

* Access Previously Generated Content
